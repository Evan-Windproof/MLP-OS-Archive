# v1.0.0 — Initial Stable Release

Release notes draft.

MLP OS Archive is an independent, multilingual reference for documenting
and preserving My Little Pony-themed operating systems, Linux
distributions, and desktop customizations. Its first collection is a
starting point for long-term preservation.

- Browse in English, Simplified Chinese, Traditional Chinese, Japanese,
  Spanish, and French. Switch languages from the corresponding archive
  page.
- Explore the Twilight-inspired light and dark design and the supplied
  Evan homepage artwork.
- Browse the three catalog categories and project detail pages, with
  development and verification status and linked historical evidence.
- Follow the historical timeline. See documented releases, download
  references, and attributed screenshot links where available.
- Propose projects, historical sources, and corrections through localized
  GitHub Issue Forms or contribute validated records through pull requests.
- The [inclusion policy](HISTORICAL_ARCHIVE_GUIDE.md#inclusion-and-assessment)
  accepts reasonable first-party evidence and records verification and
  testing separately.
- The site is generated with Astro and designed for Cloudflare Workers
  Static Assets. Accessibility and discoverability improvements include
  keyboard navigation, localized metadata, and custom 404 pages.

Before publishing, confirm the production build trigger, Worker name,
custom 404 setting, and the live responses on the official domain.
