## Gaps in published records

- **Equestria OS:** The project site and package repository corroborate the Arch
  base. An older May download page survives separately from the November file
  index. Recover any missing ISO listings and find explicit screenshot usage
  terms before copying images. Catalog screenshots are linked to the publisher.
- **PonyOS:** The first-release thread is preserved, but its historical Imgur
  images could not be retrieved. The official site has a screenshot section.
  Recover stable original image URLs, verify attribution, and find an original
  first-release binary or listing. The 9.0 AArch64 artifact remains documented
  by the publisher's release page.
- **HoofTTY:** Source and release pages are available. The archive and project
  share a maintainer. Seek independent corroboration and an attributable
  original screenshot. The catalog does not assert hardware compatibility.
- **Desktop Ponies:** SourceForge establishes an early surviving test build,
  not a creation date. Find a creator-attributed early screenshot and verify
  its usage terms before recording an image. Document the original development
  credits in more detail if contemporaneous sources are recovered.
